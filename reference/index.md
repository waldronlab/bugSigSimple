# Package index

## All functions

- [`createStudyTable()`](https://waldronlab.io/bugSigSimple/reference/createStudyTable.md)
  : Create a table of all studies currently in data.frame
- [`createTaxonTable()`](https://waldronlab.io/bugSigSimple/reference/createTaxonTable.md)
  : Create a table of most frequent taxa in a data.frame
- [`frequencySigs()`](https://waldronlab.io/bugSigSimple/reference/frequencySigs.md)
  : Identify the most frequently recurring taxa in bugsigdb
- [`getCriticalN()`](https://waldronlab.io/bugSigSimple/reference/getCriticalN.md)
  : getCriticalN performs a Monte Carlo simulation to estimate the
  number of times the most frequent taxon is expected to be observed in
  a list of signatures
- [`plotCriticalN()`](https://waldronlab.io/bugSigSimple/reference/plotCriticalN.md)
  : Visualise the Monte Carlo null distribution with threshold and CI
- [`significantTaxa()`](https://waldronlab.io/bugSigSimple/reference/significantTaxa.md)
  : Flag taxa whose observed frequency exceeds the Monte Carlo critical
  threshold
- [`simulateSignatures()`](https://waldronlab.io/bugSigSimple/reference/simulateSignatures.md)
  : Simulate a list of signatures based on a universe of taxa equal in
  size and length to some smaller set of signatures
- [`subsetByCurator()`](https://waldronlab.io/bugSigSimple/reference/subsetByCurator.md)
  : Subset a data.frame of signatures by curator
